CoreS3 IMU Logger

ミリ波レーダーSLAM用に、M5Stack CoreS3 の内蔵IMU(BMI270)を読んでUSBシリアルへ流すファームウェア。 ブラウザから直接書き込めます。

書き込む

CoreS3 を USB-C でPCに繋いでから、下のボタンを押してください。

このブラウザは Web Serial に対応していません。
Chrome または Edge（デスクトップ版）で開き直してください。 Safari と iOS では動作しません。 このページは HTTPS で開く必要があります。

押すとシリアルポートの選択ダイアログが出ます。
USB JTAG/serial debug unit や M5Stack と表示されるものを選んでください。

書き込みに失敗するとき

CoreS3 をダウンロードモードにしてから、もう一度試してください。 本体左側面のリセットボタンを約2秒長押しすると緑のLEDが点灯し、この状態になります。

ポートの一覧に何も出ない場合は、USBケーブルが充電専用でないか確認してください。 データ線の無いケーブルだと認識されません。

書き込めたかの確認

  1. 画面に IMU LOGGER (BMI270) と出る 出ない場合は書き込みが完了していません。
  2. 本体を傾けると gz の値が動く 静止させると 0 付近の小さな値に戻ります。
  3. 机に置いて数秒待つと bias measuring が bias +0.xxxx dps に変わる これが出れば準備完了です。この値がジャイロの「静止しているのに回っていると言い張る量」です。

書き込み後にこのページの「Logs & Console」を開くと、流れているデータをそのまま見られます。 I,12345678,0.0123,... のような行が毎秒100行ほど出ていれば正常です。

画面下部のタッチ操作

位置動作

次にやること

1. PC側の準備

git clone https://github.com/sat0esuS/imu1.git
cd imu1/pc
pip install -r requirements.txt
python logger.py --list

--list でシリアルポートの一覧が出ます。CoreS3 は USB Serial や M5Stack と表示されます。

2. D-1実験（MCLに入れる前に必ず）

ジャイロには必ずバイアスがあるので、素性を測ってから使います。 レーダーを繋がなくてもIMUだけで記録できます。 

# 静止60秒 × 3本（バイアスとその再現性）
python logger.py --no-radar --imu COM7 --out d1a_1 --duration 60
python logger.py --no-radar --imu COM7 --out d1a_2 --duration 60
python logger.py --no-radar --imu COM7 --out d1a_3 --duration 60

# 90°旋回 × 10回（本命。間に必ず数秒止める）
python logger.py --no-radar --imu COM7 --out d1c

# 解析
python analyze_d1.py --bias d1a_*_imu.csv --scale d1c_*_imu.csv --expect 90
判定の基準は 13.2°

このレーダーは角度分解能 26.4° なので、距離 r の点は元々 r·tan(13.2°) だけ横にぼやけています。 向きの誤差がこれを超えると、IMU由来の誤差がセンサ本来のぼやけより大きくなります。 ドリフトもスケール誤差も周回誤差も、すべてこの一本の線で合否を判断できます。

3. 本番の記録

python logger.py --cfg xwr68xx_AOP_profile.cfg \
                 --radar-cfg COM5 --radar-data COM6 --imu COM7 \
                 --out run2 --outdir data

レーダーとIMUを1つのプログラムで読み、同じ時計で時刻を打ちます。 出てくる .dat は TI Visualizer と同一形式なので、既存の解析はそのまま動きます。

このファームが何をしているか

内蔵IMUを可能な限り速く読み、1サンプル1行でUSBシリアルへ流すだけです。 積分も姿勢推定もしません。 計算をPC側に寄せてあるので、パラメータを変えて何度でもやり直せます。

行内容
I,... micros, gx, gy, gz, ax, ay, az — ジャイロ[deg/s]と加速度[G]
H,... 1秒ごとの死活確認。累計サンプル数とレート
M,... ボタン操作などの目印

micros は CoreS3 側の時刻で間隔が正確、PC側が付ける受信時刻はレーダーと共通の時計です。 imu.py が両者を1次式で対応づけて、良いところを取ります。
